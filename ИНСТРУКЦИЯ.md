# 🚀 Помощник брокера КП — PWA

Папка готова к загрузке на любой хостинг с HTTPS. После развёртывания приложение можно установить на iPhone/iPad как нативное.

## Что внутри

| Файл | Назначение |
|------|------------|
| `broker_app.html` | Основное приложение (интерфейс, клиенты, подбор банков, генерация DOCX) |
| `broker_templates.html` | Шаблоны анкет и договоров (загружаются в приложение отдельно) |
| `manifest.json` | Манифест PWA (имя, иконки, цвета, режим отображения) |
| `service-worker.js` | Service Worker для кэширования и работы офлайн |
| `icon-192.png`, `icon-512.png` | Иконки приложения |

## Как развернуть на хостинге (бесплатно)

### Вариант 1: GitHub Pages (рекомендую)

1. Зарегистрируйтесь на [github.com](https://github.com)
2. Создайте новый репозиторий, например `broker-kp-pwa`
3. Загрузите в репозиторий все 6 файлов из этой папки
4. Перейдите в **Settings → Pages**
5. В разделе **Build and deployment** выберите:
   - **Source**: Deploy from a branch
   - **Branch**: main
   - **Folder**: / (root)
6. Нажмите **Save**
7. Через 1–2 минуты появится ссылка вида: `https://ВАШ-ЛОГИН.github.io/broker-kp-pwa/`

### Вариант 2: Netlify

1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку `Брокер-КП-PWA` в окно загрузки
3. Получите ссылку вида `https://имя.netlify.app`

## Как установить на iPhone (iOS)

1. Откройте **Safari** на iPhone
2. Перейдите по ссылке на ваш хостинг (например, `https://имя.github.io/broker-kp-pwa/broker_app.html`)
3. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана)
4. Прокрутите список вниз и нажмите **«На экран «Домой»»**
5. Подтвердите имя «Помощник брокера КП»
6. Иконка появится на рабочем столе — открывайте приложение в отдельном окне

---

## Как пользоваться

1. Откройте приложение
2. Нажмите **«📦 Выбрать офлайн-файл»** и укажите `broker_templates.html` (это нужно сделать один раз)
3. Создавайте клиентов, подбирайте банки, формируйте анкеты
4. Данные клиентов сохраняются в браузере
5. Используйте **«Экспорт клиентов»** в настройках, чтобы сделать бэкап JSON-файла

## Обновление приложения

Чтобы обновить версию, замените файлы на хостинге новыми. Пользователям нужно будет обновить страницу в Safari, чтобы Service Worker подгрузил новую версию.
